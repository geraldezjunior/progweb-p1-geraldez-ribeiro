**Domínio do Projeto:**
Um sistema modular de combate estratégico por turnos (1v1) onde diferentes classes de personagens (Magos e Guerreiros) se enfrentam. O fluxo utiliza polimorfismo para aplicar habilidades especiais com bônus únicos de dano ou resistência, gerenciando dinamicamente atributos de vida e mana até a vitória.

🚀 Como Executar

1. Certifique-se de ter o **Node.js** instalado na sua máquina (versão 14 ou superior).
2. Abra o terminal na pasta do projeto (`d:\prog_web`).
3. Execute o comando de teste/demonstração:

```bash
node index.js
# ou
npm start
```
